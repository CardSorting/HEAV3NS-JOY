# HEAV3NS-JOY: Фреймворк архитектурного суверенитета и контроля структурной энтропии

[English](../../README.md) · [Другие языки](README.md) · [Начало работы](../GETTING_STARTED.md) · [Протокол агентов](../../AGENTS.md)

> *«Не создавайте еще одно место, где запускаются агенты. Создайте то, чему агенты смогут научиться, унести с собой и независимо воспроизвести где угодно.»*

**В одном предложении:** HEAV3NS-JOY сохраняет архитектурную чистоту кодовых баз (как написанных человеком, так и созданных ИИ-агентами) с помощью минимальной конвенции и чекера без зависимостей.

---

## Идея за 60 секунд

| Измерение | Описание |
| :--- | :--- |
| **Что это** | Соглашение и инструмент аудита без зависимостей. Каждый файл объявляет одну из пяти канонических зон (`DOMAIN`, `CORE`, `INFRASTRUCTURE`, `PLUMBING`, `UI`) в заголовке первой строки. |
| **Зачем** | Архитектура деградирует незаметно, а ИИ-агенты ускоряют эту деградацию. Машинная проверка структуры останавливает эрозию на этапе коммита, а не при переписывании проекта. |
| **Как** | Поместите файл в папку соответствующей зоны, импортируйте только в разрешенных направлениях и запустите `node bin/joy-check.mjs .`. Код `0` подтверждает соответствие. |
| **Стоимость** | **Ноль внешних зависимостей**, без учетных записей, без сети, только для чтения по умолчанию. |

### Аналогия с рестораном

Представьте кодовую базу как ресторан:
- **Кухня (`DOMAIN`)**: Чистые рецепты и бизнес-правила; категорически запрещено звонить поставщикам посреди приготовления блюда.
- **Диспетчерская (`CORE`)**: Координация заказов и сценариев использования.
- **Поставщики (`INFRASTRUCTURE`)**: Адаптеры для файловой системы, HTTP и баз данных.
- **Обеденный зал (`UI`)**: Обслуживание клиентов и отрисовка экранов; никогда не заходит в кладовую.
- **Коммуникации (`PLUMBING`)**: Чистые функции-утилиты без состояния, полностью изолированные.

## Пять канонических зон

| Зона | Директория | Ответственность | Жесткое правило |
| :--- | :--- | :--- | :--- |
| `DOMAIN` | `src/domain/` | Бизнес-правила, сущности, контракты `I*` | **0% энтропии ввода-вывода**; запрещен импорт инфраструктуры или UI |
| `CORE` | `src/core/` | Оркестрация сценариев, машины состояний | Запрещен импорт UI; взаимодействие с инфраструктурой только через интерфейсы |
| `INFRASTRUCTURE` | `src/infrastructure/` | Адаптеры fs, HTTP, баз данных | Запрещен импорт UI; реализует контракты Domain |
| `PLUMBING` | `src/plumbing/` | Криптография, утилиты без состояния | Листовой слой; запрещен импорт любых других зон |
| `UI` | `src/ui/` | CLI-презентеры, HTTP-роуты, экраны | Запрещен прямой импорт инфраструктуры |

## Быстрый старт (2 минуты)

Установка `npm install` не требуется (нужны только Node.js 18+ и git):

```bash
git clone https://github.com/CardSorting/HEAV3NS-JOY.git
cd HEAV3NS-JOY

# 1. Запуск набора тестов (196 тестов пройдено)
npm test

# 2. Аудит архитектурного соответствия
npm run joy-check

# 3. Настройка ИИ-агентов (Claude, Cursor, Antigravity и др.)
npx heav3ns-joy init
```

Подробности в [Портале документации](../README.md) и [Канонической модели](../../spec/00-CANONICAL-MODEL.md).
