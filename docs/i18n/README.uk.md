# HEAV3NS-JOY: Фреймворк архітектурного суверенітету та контролю структурної ентропії

[English](../../README.md) · [Інші мови](README.md) · [Початок роботи](../GETTING_STARTED.md) · [Протокол агентів](../../AGENTS.md)

> *«Не створюйте ще одне місце, де запускаються агенти. Створіть те, чого агенти можуть навчитися, забрати із собою та незалежно відтворити будь-де.»*

**В одному реченні:** HEAV3NS-JOY зберігає архітектурну чистоту кодових баз (як написаних людиною, так і створених ШІ-агентами) за допомогою мінімальної конвенції та перевірки без залежностей.

---

## Ідея за 60 секунд

| Вимір | Опис |
| :--- | :--- |
| **Що це** | Угода та інструмент аудиту без залежностей. Кожен файл декларує одну з п'яти канонічних зон (`DOMAIN`, `CORE`, `INFRASTRUCTURE`, `PLUMBING`, `UI`) у верхньому заголовку. |
| **Чому** | Архітектура деградує непомітно, а ШІ-агенти прискорюють цей процес. Перевірка структури машинами зупиняє ерозію на етапі коміту, а не під час коштовного переписування. |
| **Як** | Розмістіть файл у папці відповідної зони, імпортуйте тільки у дозволених напрямках та запустіть `node bin/joy-check.mjs .`. Код `0` підтверджує відповідність. |
| **Вартість** | **Нуль зовнішніх залежностей**, без облікових записів, без мережі, тільки для читання за замовчуванням. |

### Аналогія з рестораном

Уявіть кодову базу як ресторан:
- **Кухня (`DOMAIN`)**: Чисті рецепти та бізнес-правила; категорично заборонено телефонувати постачальникам посеред приготування страви.
- **Диспетчерська (`CORE`)**: Координація замовлень та сценаріїв використання.
- **Постачальники (`INFRASTRUCTURE`)**: Адаптери для файлової системи, HTTP та баз даних.
- **Обідня зала (`UI`)**: Обслуговування клієнтів та відображення інтерфейсів; ніколи не заходить до комори.
- **Комунікації (`PLUMBING`)**: Чисті утиліти без стану, повністю ізольовані.

## П'ять канонічних зон

| Зона | Директорія | Відповідальність | Суворе правило |
| :--- | :--- | :--- | :--- |
| `DOMAIN` | `src/domain/` | Бізнес-правила, сутності, контракти `I*` | **0% ентропії вводу-виводу**; заборонено імпорт інфраструктури або UI |
| `CORE` | `src/core/` | Оркестрація сценаріїв, машини станів | Заборонено імпорт UI; взаємодія з інфраструктурою лише через інтерфейси |
| `INFRASTRUCTURE` | `src/infrastructure/` | Адаптери fs, HTTP, баз даних | Заборонено імпорт UI; реалізує контракти Domain |
| `PLUMBING` | `src/plumbing/` | Криптографія, утиліти без стану | Листовий шар; заборонено імпорт будь-яких інших зон |
| `UI` | `src/ui/` | CLI-презентери, HTTP-роути, інтерфейси | Заборонено прямий імпорт інфраструктури |

## Швидкий старт (2 хвилини)

Встановлення `npm install` не потрібне (потрібні лише Node.js 18+ та git):

```bash
git clone https://github.com/CardSorting/HEAV3NS-JOY.git
cd HEAV3NS-JOY

# 1. Запуск тестового набору (196 тестів пройдено)
npm test

# 2. Аудит архітектурної відповідності
npm run joy-check

# 3. Налаштування ШІ-агентів (Claude, Cursor, Antigravity тощо)
npx heav3ns-joy init
```

Докладніше у [Порталі документації](../README.md) та [Канонічній моделі](../../spec/00-CANONICAL-MODEL.md).
