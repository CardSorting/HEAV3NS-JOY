# HEAV3NS-JOY: वास्तुकला संप्रभुता और संरचनात्मक एन्ट्रॉपी नियंत्रण ढांचा

**एक वाक्य में:** HEAV3NS-JOY एक न्यूनतम परिपाटी और शून्य-निर्भरता विश्लेषक के माध्यम से आपके कोडबेस को वास्तुशिल्प रूप से ईमानदार बनाए रखता है।

## 60 सेकंड में मूल विचार

| पहलू | विवरण |

### रेस्तरां की उपमा

कोडबेस को एक रेस्तरां की तरह समझें:
- **रसोई (`DOMAIN`)**: शुद्ध रेसिपी और व्यावसायिक नियम; खाना पकाने के बीच में आपूर्तिकर्ताओं को कॉल करना सख्त मना है।
- **समन्वय (`CORE`)**: ऑर्डर और उपयोग-मामलों का समन्वय।
- **आपूर्तिकर्ता (`INFRASTRUCTURE`)**: फ़ाइल सिस्टम, HTTP और डेटाबेस एडेप्टर।
- **डाइनिंग रूम (`UI`)**: ग्राहकों की सेवा और स्क्रीन रेंडर करना; कभी भी पेंट्री में नहीं जाता।
- **प्लंबिंग (`PLUMBING`)**: स्थितिहीन उपयोगिता फ़ंक्शन, पूरी तरह से पृथक।

## पाँच विहित क्षेत्र

| क्षेत्र | निर्देशिका | जिम्मेदारी | अपरिवर्तनीय नियम |
| :--- | :--- | :--- | :--- |
| `DOMAIN` | `src/domain/` | व्यावसायिक नियम, संस्थाएं, अनुबंध `I*` | **0% I/O एन्ट्रॉपी**; इंफ्रा या UI आयात वर्जित |
| `CORE` | `src/core/` | उपयोग-मामला ऑर्केस्ट्रेशन, स्टेट मशीन | UI आयात वर्जित; इंटरफेस के माध्यम से इंफ्रा से जुड़ता है |
| `INFRASTRUCTURE` | `src/infrastructure/` | fs, HTTP, डेटाबेस एडेप्टर | UI आयात वर्जित; Domain अनुबंधों को लागू करता है |
| `PLUMBING` | `src/plumbing/` | क्रिप्टोग्राफी, स्टेटलेस उपयोगिताएँ | लीफ परत; किसी अन्य क्षेत्र को आयात नहीं कर सकता |
| `UI` | `src/ui/` | CLI प्रस्तुतकर्ता, HTTP रूट, दृश्य | सीधे इंफ्रास्ट्रक्चर आयात करना वर्जित है |

## त्वरित शुरुआत (2 मिनट)

`npm install` की आवश्यकता नहीं है (केवल Node.js 18+ और git):

```bash
git clone https://github.com/CardSorting/HEAV3NS-JOY.git
cd HEAV3NS-JOY

# 1. टेस्ट चलाएं (196 टेस्ट सफल)
npm test

# 2. वास्तुकला ऑडिट चलाएं
npm run joy-check

# 3. AI एजेंट कॉन्फ़िगरेशन स्थापित करें (Claude, Cursor, Antigravity आदि)
npx heav3ns-joy init
```

अधिक जानकारी [दस्तावेज़ीकरण पोर्टल](../README.md) और [कैनोनिकल मॉडल](../../spec/00-CANONICAL-MODEL.md) में देखें।
