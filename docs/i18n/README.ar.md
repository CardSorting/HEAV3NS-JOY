# HEAV3NS-JOY: إطار السيادة المعمارية والتحكم في الإنتروبيا الهيكلية

[English](../../README.md) · [لغات أخرى](README.md) · [دليل البداية](../GETTING_STARTED.md) · [بروتوكول الوكلاء](../../AGENTS.md)

> *“لا تبنِ مكانًا آخر ليعمل فيه الوكلاء. ابنِ شيئًا يمكن للوكلاء التعلم منه، وحمله معهم، وإعادة إنتاجه بشكل مستقل في أي مكان.”*

**في جملة واحدة:** يحافظ HEAV3NS-JOY على نزاهة قواعد الأكواد الخاصة بك (سواء التي كتبها البشر أو أنشأتها وكلاء الذكاء الاصطناعي) باستخدام اصطلاح مقتضب وأداة تدقيق بدون تبعيات خارجية.

---

## الفكرة في 60 ثانية

| البعد | التفاصيل |
| :--- | :--- |
| **ما هو** | اصطلاح تقني وأداة تدقيق خفيفة بدون أي تبعيات. يصرح كل ملف في السطر الأول عن إحدى المناطق المعيارية الخمس (`DOMAIN`، `CORE`، `INFRASTRUCTURE`، `PLUMBING`، `UI`). |
| **لماذا** | تتآكل المعمارية بصمت، وتسرع وكلاء الذكاء الاصطناعي هذا التدهور. التحقق الآلي من البنية يوقف التآكل عند الـ commit، بدلاً من إعادة كتابة النظام لاحقًا. |
| **كيف** | ضع كل ملف في مجلد منطقته، واستورد فقط في الاتجاهات المسموحة، وشغّل `node bin/joy-check.mjs .`. رمز الخروج `0` يعني سلامة معمارية تامة. |
| **التكلفة** | **صفر تبعيات خارجية**، لا حاجة لحسابات، لا حاجة لشبكة، للقراءة فقط افتراضيًا. |

### تشبيه المطعم

تخيل قاعدة الكود كمطعم:
- **المطبخ (`DOMAIN`)**: يُعد الوصفات النقية وقواعد العمل؛ يُحظر تمامًا الاتصال بالموردين أثناء الطهي.
- **إدارة الطلبات (`CORE`)**: تنسيق تدفق الطلبات وحالات الاستخدام.
- **الموردون (`INFRASTRUCTURE`)**: محولات نظام الملفات، HTTP وقواعد البيانات.
- **صالة الطعام (`UI`)**: استقبال العملاء ورسم الواجهات؛ لا تدخل أبدًا إلى مستودع المكونات.
- **التمديدات (`PLUMBING`)**: أدوات برمجية عديمة الحالة ونقية ومعزولة تمامًا.

## المناطق المعيارية الخمس

| المنطقة | المجلد | المسؤولية | القاعدة الصارمة |
| :--- | :--- | :--- | :--- |
| `DOMAIN` | `src/domain/` | قواعد العمل، الكيانات، عقود `I*` | **0% إنتروبيا إدخال/إخراج**؛ يُحظر استيراد البنية التحتية أو الواجهة |
| `CORE` | `src/core/` | تنظيم حالات الاستخدام، آلات الحالة | يُحظر استيراد الواجهة؛ التعامل مع البنية التحتية عبر واجهات فقط |
| `INFRASTRUCTURE` | `src/infrastructure/` | محولات الملفات والشبكة وقواعد البيانات | يُحظر استيراد الواجهة؛ تطبيق عقود Domain |
| `PLUMBING` | `src/plumbing/` | التشفير، الأدوات عديمة الحالة | طبقة فرعية؛ يُحظر استيراد أي منطقة أخرى |
| `UI` | `src/ui/` | سطر الأوامر، مسارات HTTP، العرض | يُحظر استيراد البنية التحتية مباشرة |

## البداية السريعة (دقيقتان)

لا حاجة لتثبيت حزم `npm` (فقط Node.js 18+ و git):

```bash
git clone https://github.com/CardSorting/HEAV3NS-JOY.git
cd HEAV3NS-JOY

# 1. تشغيل الاختبارات (196 اختبارًا ناجحًا)
npm test

# 2. تدقيق الامتثال المعماري
npm run joy-check

# 3. تثبيت إعدادات الوكلاء (Claude, Cursor, Antigravity إلخ)
npx heav3ns-joy init
```

لمزيد من المعلومات، راجع [بوابة التوثيق](../README.md) و [النموذج المعياري](../../spec/00-CANONICAL-MODEL.md).
