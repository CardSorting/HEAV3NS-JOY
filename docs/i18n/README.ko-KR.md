# HEAV3NS-JOY: 아키텍처 주권 및 구조적 엔트로피 제어 프레임워크

[English](../../README.md) · [다른 언어](README.md) · [시작하기](../GETTING_STARTED.md) · [Agent 프로토콜](../../AGENTS.md)

> *“에이전트가 실행되는 장소를 또 하나 만들지 마십시오. 에이전트가 학습하고, 가져가며, 어디서나 독립적으로 재현할 수 있는 시스템을 구축하십시오.”*

**한 줄 요약:** HEAV3NS-JOY는 극소의 규칙과 무의존성 검사기를 통해 사람과 AI 에이전트의 코드베이스 아키텍처 오염을 완벽히 방지합니다.

---

## 60초 핵심 요약

| 항목 | 내용 |
| :--- | :--- |
| **정의** | 5대 정규 구역(`DOMAIN`, `CORE`, `INFRASTRUCTURE`, `PLUMBING`, `UI`)을 첫 줄 헤더로 선언하는 규칙과 초경량 검사기. |
| **목적** | 아키텍처는 조용히 침식되며, AI 코딩 에이전트는 이를 가속합니다. 커밋 시점에 기계가 검증함으로써 전체 재작성의 재앙을 막습니다. |
| **방법** | 각 파일을 정해진 물리적 폴더에 배치하고, 허용된 방향으로만 임포트하며, `node bin/joy-check.mjs .`를 실행합니다. 종료 코드 `0`은 건전성을 보장합니다. |
| **비용** | **외부 의존성 제로(0)**, 계정 불필요, 네트워크 불필요, 기본 읽기 전용. |

### 레스토랑 비유

코드베이스를 레스토랑으로 비유해 보세요:
- **주방 (`DOMAIN`)**: 순수한 요리 레시피와 핵심 비즈니스 규칙. 조리 도중 식자재 공급업체에 직접 전화하는 것은 엄격히 금지됩니다.
- **주문 배차 (`CORE`)**: 주문 흐름과 유스케이스 조율.
- **공급망 어댑터 (`INFRASTRUCTURE`)**: 파일시스템, HTTP, 데이터베이스 I/O 담당.
- **홀 객석 (`UI`)**: 손님의 요청을 접수하고 화면을 렌더링. 식자재 창고에 직접 들어갈 수 없습니다.
- **배관 설비 (`PLUMBING`)**: 상태가 전혀 없는 순수 유틸리티 함수. 다른 구역에 의존하지 않습니다.

## 5대 정규 구역

| 구역 | 물리 폴더 | 책임과 역할 | 엄격한 불변 원칙 |
| :--- | :--- | :--- | :--- |
| `DOMAIN` | `src/domain/` | 비즈니스 규칙, 엔티티, 인터페이스 계약 (`I*`) | **0% I/O**; 인프라나 UI 임포트 절대 금지 |
| `CORE` | `src/core/` | 유스케이스 오케스트레이션, 상태 머신 | UI 임포트 금지; 인프라는 인터페이스를 통해서만 연동 |
| `INFRASTRUCTURE` | `src/infrastructure/` | 파일, HTTP, DB 어댑터 구현체 | UI 임포트 금지; Domain의 인터페이스 계약을 구현 |
| `PLUMBING` | `src/plumbing/` | 상태 없는 유틸리티, 암호화, 경로 파싱 | 리프(Leaf) 레이어; 다른 구역 임포트 절대 금지 |
| `UI` | `src/ui/` | CLI 프레젠터, HTTP 라우팅, 프런트엔드 | 인프라 직접 임포트 절대 금지 |

## 빠른 시작 (2분)

Node.js 18+와 git만 있으면 npm 설치 없이 바로 실행됩니다:

```bash
git clone https://github.com/CardSorting/HEAV3NS-JOY.git
cd HEAV3NS-JOY

# 1. 테스트 실행 (196개 테스트 통과)
npm test

# 2. 아키텍처 주권 감사
npm run joy-check

# 3. 에이전트 설정 자동 설치 (Claude, Cursor, Antigravity 등)
npx heav3ns-joy init
```

자세한 내용은 [문서 포털](../README.md) 및 [명세서](../../spec/00-CANONICAL-MODEL.md)를 참조하십시오.
