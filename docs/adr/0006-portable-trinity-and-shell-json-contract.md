# ADR-0006: Portable Broccoli Trinity & Harness-Agnostic Shell-In/JSON-Out Contract

## Status

Accepted — Implemented in [`bin/joy-trinity.mjs`](../../bin/joy-trinity.mjs) and [`src/portable.mjs`](../../src/portable.mjs).

## Context

AI coding agents run inside wildly different harnesses (Claude Code, Gemini CLI, Antigravity, Cursor, Copilot, Windsurf, Codex, Cline, CI scripts, custom loops). Most agents cannot modify their own host harness or keep an in-process Node daemon alive across turns, yet they frequently need:
1. **Durable, idempotent job queues** (`BroccoliQueue`)
2. **Buffered write-behind tables with shadow transactions** (`BufferedDb`)
3. **Multi-specialist task classification, dependency-ordered DAG planning, step-wise ledger execution, and durable workspace heuristic memory** (`AgentSwarm` / `SwarmFormationLedger` / `SwarmKnowledgeService`)

When multiple shell invocations access the same state directory (`.joy-state`) concurrently, or when a worker process crashes mid-command, unprotected WAL files can corrupt or orphan locks forever ([`PM-002`](../postmortems/PM-002-multi-process-wal-contention-and-orphaned-root-locks.md)).

### Decision drivers

- **Universal Harness Compatibility**: Any agent that can run a shell command and parse stdout JSON must be able to drive queues, tables, and specialist swarms without a daemon or SDK.
- **Cross-Process Safety**: Concurrent CLI calls against the same `--root` must serialize safely, and locks left by crashed processes on the same host must be reclaimed automatically.
- **Deterministic Exit & Output Contract**: Stdout in default `--format json` must always be a single valid JSON envelope (`{"ok":true,...}` or `{"ok":false,"error":...}`), with exit codes `0` (ok), `1` (runtime failure), and `2` (usage error with Levenshtein `hint`).

### Considered options

1. **Require a Long-Running Background Daemon**: Fails in serverless CI, ephemeral container steps, and harnesses that kill background processes after each tool call.
2. **In-Memory Library Only**: Useless for shell-only agents because state vanishes when the command exits.
3. **Process-Per-Command CLI (`bin/joy-trinity.mjs`) + Exclusive `.joy-lock` (`FileRootLock`) + Step-Wise `SwarmFormationLedger` + Programmatic `heav3ns-joy/portable` API**.

## Decision

We chose **Option 3**:

1. **Shell-In / JSON-Out Contract (`bin/joy-trinity.mjs`)**:
   - Every command opens `--root` (default `./.joy-state`), acquires `.joy-lock` via [`FileRootLock.mjs`](../../src/infrastructure/FileRootLock.mjs), replays the embedded BroccoliDB WAL, executes the operation, flushes `BufferedDb`, stops the kernel, and releases `.joy-lock`—including on `SIGINT`/`SIGTERM` (`130`/`143`).
   - If another live PID holds `.joy-lock` past `--lock-timeout-ms` (default 10s), it fails cleanly with `ROOT_LOCKED`. If the lock holder PID is dead on the current host (`process.kill(pid, 0)`), the lock is reclaimed atomically.
2. **Three Swarm Execution Modes**:
   - **Step-wise Ledger (`swarm plan` → `swarm next` / `swarm report` → `swarm finish`)**: Works in any shell; the calling agent or its subagents perform specialist work using self-contained prompts generated by `SwarmFormationLedger`.
   - **External Process (`swarm run --exec '["cmd","arg"]')`**: Spawns one subprocess per specialist via [`ProcessAgentEngine.mjs`](../../src/infrastructure/ProcessAgentEngine.mjs) with zero shell interpolation.
   - **Embedded (`AgentSwarmDispatcher`)**: In-process orchestration via [`ISwarmAgentEngine`](../../src/domain/interfaces/ISwarmAgentEngine.mjs).
3. **Sanitized Workspace Knowledge (`SwarmKnowledgeService`)**:
   - Persists validated `Heuristic: <fact>` lines in `BufferedDb` (`agent_knowledge`), scoped by SHA-256 of the workspace path (`legionWorkspaceScope`), rejecting credentials/secrets/control chars and replaying them inside `<workspace_heuristics trust="untrusted">`.

## Consequences

### Positive

- Zero harness integration required: `node bin/joy-trinity.mjs selftest` proves the entire stack in < 1 second.
- Safe under parallel `spawn` storms (verified by 8-way concurrency test in `Suite 27`).

### Negative / trade-offs

- Each CLI call pays a few milliseconds of WAL open/flush overhead; long-lived Node hosts can avoid this by importing `createPortableBroccoli` from `heav3ns-joy/portable`.
