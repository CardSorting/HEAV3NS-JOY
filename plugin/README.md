# joy — Claude Code plugin

Generated by `npm run plugin:build` from the same templates as `joy init`; do not edit by hand.

Install: `/plugin marketplace add CardSorting/HEAV3NS-JOY` then `/plugin install joy@heav3ns-joy`.

Provides skills (joyzoning, joy-trinity, joy-swarm), commands (`/joy:joy-check`, `/joy:joy-swarm`), the `joy-auditor` subagent, and the `joy` MCP server (npx -y heav3ns-joy@1.0.0 mcp).
For project instruction files (AGENTS.md, SOUL.md) and the optional post-edit hook run `npx -y heav3ns-joy@1.0.0 init`.
